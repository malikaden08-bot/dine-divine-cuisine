# Dine Divine Cuisine - Premium Full-Stack Fast Food Restaurant Website & Admin Dashboard

Production-ready, fully responsive, high-performance web application built with Next.js (App Router), TypeScript, Framer Motion, and Tailwind CSS for **Dine Divine Cuisine** located at AECHS Food Street, Rawalpindi, Pakistan.

## Features
- **Public Gourmet Storefront**: Interactive Menu with Real-Time Filters, Daily Deals, Chef Recommendations, Lightbox Gallery, and Customer Reviews.
- **Customer Authentication**: Google OAuth and Email sign-in for saved profiles and auto-filled delivery checkout.
- **Live Order Tracker**: Visual step pipeline (`Order Received` ➔ `Kitchen Cooking` ➔ `Out for Delivery` ➔ `Delivered`) with ETA countdown and rider dispatch hotline.
- **Direct Order Notifications**: Instant email receipts sent to `adenazeem595959@gmail.com` and 1-click WhatsApp order dispatch to `+923338280577`.
- **Payment Slip Uploads**: Attach transaction screenshots during checkout for JazzCash, EasyPaisa, and Bank Transfer.
- **Admin Dashboard (`/admin`)**: Real-time Order Management Queue, Live Menu CRUD with local PC image upload, Payment Gateway Configurator, and Site Settings editor.
